  <name>Task 2: Refactor qa.$questionId.tsx with useFetcher, security chain, VoteButtons, and ConfirmModal</name>

  <action>
This is the major refactor of `app/routes/qa.$questionId.tsx`. The file currently has ~445 lines with DOM-injected vote forms, browser confirm() for deletes, and no security. Replace with production-ready implementation.

**Loader changes:**
- Import and call `getCSRFToken(request)` — add `csrfToken: token` to loader data, pass headers
- Return `csrfToken` alongside existing question, answers, user, userVotes data

**Action changes — apply security chain to ALL actions:**
- Import `requireCSRFToken`, `applyRateLimit`, `logAuditEvent`, `getClientInfo`
- At the top of the action, before the switch: `await requireCSRFToken(request, formData)`
- For the `_action` switch cases, add rate limiting per user decision:
  - `answer`: `applyRateLimit(request, 'api', userId)` — 100/min
  - `voteQuestion` / `voteAnswer`: `applyRateLimit(request, 'api', userId)` — 100/min
  - `acceptAnswer`: `applyRateLimit(request, 'api', userId)` — 100/min
  - `deleteQuestion` / `deleteAnswer`: `applyRateLimit(request, 'api', userId)` — 100/min
- For vote actions: the self-vote check now happens inside voteQuestion/voteAnswer (Plan 01). Catch the thrown error and return `data({ error: 'Cannot vote on own content' }, { status: 403 })`.
- For delete actions ONLY: add audit logging after successful deletion:
  ```typescript
  const { ipAddress, userAgent } = getClientInfo(request);
  await logAuditEvent({ userId, action: 'delete', resource: 'question', resourceId: questionId, ipAddress, userAgent });
  ```

**Component refactor — replace DOM forms with useFetcher components:**

1. **Remove the existing inline VoteButtons function** that uses `document.createElement('form')`. Replace all vote UI with the `VoteButtons` component from `components/qa/VoteButtons.tsx`.

2. **Question voting:** Replace the question vote section with:
   ```tsx
   <VoteButtons
     type="question"
     targetId={question.id}
     voteCount={question.voteCount}
     userVote={userVotes.questionVote}
     csrfToken={csrfToken}
     disabled={!user || question.authorId === user.id}
   />
   ```

3. **Answer voting:** For each answer in the map, replace vote buttons with:
   ```tsx
   <VoteButtons
     type="answer"
     targetId={answer.id}
     voteCount={answer.voteCount}
     userVote={userVotes.answerVotes[answer.id] || 0}
     csrfToken={csrfToken}
     disabled={!user || answer.authorId === user.id}
   />
   ```

4. **Accept answer:** Replace the current form with `useFetcher`:
   - Create `const acceptFetcher = useFetcher()`
   - Replace the accept form with `acceptFetcher.Form` containing hidden inputs for `_csrf`, `_action: 'acceptAnswer'`, `answerId`
   - Show optimistic accepted state when `acceptFetcher.formData` exists

5. **Answer form:** Add `<input type="hidden" name="_csrf" value={csrfToken} />` to the existing answer submission form.

6. **Delete question:** Replace `confirm()` with ConfirmModal:
   - Add state: `const [deleteQuestionOpen, setDeleteQuestionOpen] = useState(false)`
   - Create `const deleteQuestionFetcher = useFetcher()`
   - Replace the delete button's onClick (which currently uses confirm()) with `onClick={() => setDeleteQuestionOpen(true)}`
   - Render `<ConfirmModal isOpen={deleteQuestionOpen} onClose={() => setDeleteQuestionOpen(false)} onConfirm={() => { deleteQuestionFetcher.submit({ _action: 'deleteQuestion', _csrf: csrfToken }, { method: 'post' }); setDeleteQuestionOpen(false); }} title="Delete Question" message="Are you sure you want to delete this question? This action cannot be undone." isLoading={deleteQuestionFetcher.state !== 'idle'} />`

7. **Delete answer:** Same ConfirmModal pattern. Since there are multiple answers, track which answer is being deleted:
   - Add state: `const [deleteAnswerId, setDeleteAnswerId] = useState<string | null>(null)`
   - Create `const deleteAnswerFetcher = useFetcher()`
   - Each answer's delete button sets `setDeleteAnswerId(answer.id)`
   - Single ConfirmModal at the bottom: `isOpen={!!deleteAnswerId}`, onConfirm submits with `{ _action: 'deleteAnswer', answerId: deleteAnswerId, _csrf: csrfToken }`

8. **Clean up:** Remove any `document.createElement`, `document.body.appendChild`, or direct DOM manipulation related to forms. Remove any `window.confirm()` calls.
