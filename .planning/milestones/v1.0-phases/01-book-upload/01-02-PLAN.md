**2. Create `app/routes/admin.books.tsx`:**

This is the main admin book management route at `/admin/books`.

**Loader:**
```typescript
export const loader = async ({ request }: LoaderFunctionArgs) => {
  const user = await getUser(request);
  if (!isAdmin(user)) throw redirect("/progress");

  const { token, headers } = await getCSRFToken(request);
  const books = await getAllBooks(); // all books including inactive, excluding soft-deleted
  return data({ books, csrfToken: token, user }, { headers });
};
```

**Action handler with multiple actions (via `_action` field):**

Use `unstable_composeUploadHandlers`, `unstable_createMemoryUploadHandler`, and `unstable_parseMultipartFormData` from `@remix-run/node` for the `createBook` action. Other actions (updateBook, toggleActive, softDelete) use regular `request.formData()` since they don't involve file uploads (except updateBook with optional PDF replacement -- that also needs multipart parsing).

**Actions to handle:**

a) `_action === "createBook"`:
   - Auth check: `requireUserId` + `isAdmin` guard
   - Rate limit: `applyRateLimit(request, "upload", userId)`
   - Parse multipart form data with composed upload handlers:
     - Custom handler for "pdfFile" field: validate it's PDF, then call `uploadStreamToCloudinary(data, { folder: "maths-joy/books", resource_type: "raw" })` and store result
     - Custom handler for "thumbnailFile" field: validate it's image, then call `uploadStreamToCloudinary(data, { folder: "maths-joy/book-thumbnails", resource_type: "image" })` and store result
     - Fall through to `unstable_createMemoryUploadHandler()` for all text fields
   - After parsing: validate CSRF token, validate required fields using `validateBookFields`, validate price using `validateBookPrice`
   - If validation fails and files were uploaded, delete orphaned Cloudinary uploads using `deleteFromCloudinary`
   - Build translation object using `createTranslation` from `i18n.server.ts`:
     ```typescript
     const translation = createTranslation(
       { title: title_el, description: description_el },
       { title: title_en, description: description_en }
     );
     ```
   - Call `createBook` with all fields + Cloudinary results
   - Log audit event via `logAuditEvent`
   - Return `data({ success: true })` or error response

b) `_action === "updateBook"`:
   - Auth + CSRF + rate limit checks
   - Parse multipart form data (same composed handler pattern -- PDF and thumbnail are optional for updates)
   - Get `bookId` from form data
   - Build update object with only provided fields
   - If new PDF uploaded: pass new cloudinaryPublicId/cloudinaryUrl to `updateBook` (which handles archiving internally)
   - If new thumbnail uploaded: pass new thumbnailUrl/thumbnailPublicId
   - Update translation if language fields changed
   - Call `updateBook(bookId, updateData)`
   - Return updated book data or errors

c) `_action === "toggleActive"`:
   - Auth + CSRF checks (no rate limit needed for toggle)
   - Get `bookId` from form data
   - Call `toggleBookActive(bookId)`
   - Return success

d) `_action === "softDelete"`:
   - Auth + CSRF checks
   - Get `bookId` from form data
   - Call `softDeleteBook(bookId)`
   - Return success
