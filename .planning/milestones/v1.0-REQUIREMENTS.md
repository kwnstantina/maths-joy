## v1.0 Requirements (Books & Payments)

- [x] **BOOK-01**: Admin can upload book PDF with thumbnail, title, description, category, tags, price — Phase 1
- [x] **BOOK-02**: Student can browse book catalog with categories — Phase 2
- [x] **BOOK-03**: Student can purchase book via Stripe checkout — Phase 2
