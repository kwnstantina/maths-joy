**2. Component: derive filter state variables**

**3. Component: add unanswered toggle handler**

Add a handler alongside existing filter handlers:
```typescript
const handleUnansweredToggle = () => {
  const newParams = new URLSearchParams(searchParams);
  if (currentUnanswered) {
    newParams.delete('unanswered');
  } else {
    newParams.set('unanswered', 'true');
  }
  newParams.delete('page');
  setSearchParams(newParams);
};
```

**4. Component: add clearAllFilters handler**

```typescript
const clearAllFilters = () => {
  const newParams = new URLSearchParams();
  const sortVal = searchParams.get('sort');
  if (sortVal) newParams.set('sort', sortVal);
  setSearchParams(newParams);
};
```

Add an "Unanswered" toggle button below the search form and above the categories section:
