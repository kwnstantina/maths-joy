<objective>
Rewire the public `/exercises` page to use server-side filtering + pagination via the extended `getPaginatedExercises` from 06-01, and make the existing `SearchInput` component drive URL searchParams instead of local state. The URL and DB storage both stay Greek-canonical; only the visible dropdown LABELS switch languages. The shared `Pagination` component was already created in Plan 06-01 (Task 3); this plan simply imports it.

Purpose: Currently `exercises._index.tsx` calls `getAllExcersices()` (loads EVERY row) and filters in-memory. At 200+ exercises this becomes a noticeable page-load. EX-04 demands server-side pagination; EX-03 demands text search over title + description + tags. The 06-01 plan delivered the server-side filter signature + the shared Pagination component — this plan consumes both and fixes the UI to match. Greek-canonical URLs eliminate the round-trip ambiguity where a Greek-mode user and an English-mode user opening the same shared link could otherwise see different results.

Output:
- Rewired `/exercises` loader using `getPaginatedExercises` with raw Greek-canonical URL params (no EN→EL mapping layer)
- `SearchInput` rewired to push filter state to URL; in en-mode, dropdowns display English labels but emit Greek values
- Empty-state UX preserved
- English-mode label translation via `TAGS_En` / `Type_En` / `Category_En` pairing — at render time only
</objective>

## URL → filter contract (Greek-canonical, this plan defines)
Per CONTEXT.md: "Keep URL values and DB values Greek-canonical everywhere; only presentation layer switches to English."

- `?category=` → Greek canonical name from `Category.byId` (e.g. `?category=Άλγεβρα`, NEVER `?category=Algebra`)
- `?level=` → Greek canonical name from `TAGS.byId` (e.g. `?level=Α-Λυκείου`)
- `?type=` → Greek canonical name from `Type.byId` (e.g. `?type=Λυμένες ασκήσεις`)
- `?input=` → text search (passed through to `getPaginatedExercises` unchanged)
- `?page=` → 1-based page number (default 1)

Backward compat: current `SearchInput` uses the old keys `title` (for level) and `tags` (for type). The loader accepts those old keys as fallbacks so stale bookmarks keep working.
