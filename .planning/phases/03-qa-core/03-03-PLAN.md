- `case 'editAnswer'`: Extract answerId and body from formData. Call `updateAnswer(answerId, body)`. Return `data({ success: true })`.

**Question inline editing UI:**
Follow the BookCard pattern from `components/admin/BookCard.tsx`:
- Add state: `const [editingQuestion, setEditingQuestion] = useState(false)`
- Create `const editQuestionFetcher = useFetcher()`
- Show an "Edit" button next to the question (visible only to question author: `question.authorId === user?.id`)
- When editingQuestion is true, replace the question display (title, body) with an edit form:
  - Title input (text field, pre-filled with current title)
  - Body textarea (pre-filled with current body)
  - Category select (pre-filled, same options as qa.ask.tsx)
  - Tags input (pre-filled with comma-separated tags)
  - Hidden inputs: `_csrf`, `_action: 'editQuestion'`
  - Save button (submits via editQuestionFetcher.Form) and Cancel button (sets editingQuestion to false)
- useEffect to exit edit mode when editQuestionFetcher returns success:
